Note on **`get`**: `SwitchBCM56860HW::get` (`SwitchBCM56860HW.cpp:3253-3335`) does not intercept any Domain 2 object; all Domain 2 `get` calls return vslib SW DB values.
Note on **capability queries**: `SwitchBCM56860HW` does NOT override `queryAttributeCapability` (`SwitchStateBase.cpp:4152-4170` returns `create=set=get=true` for ALL attributes!) or `queryAttrEnumValuesCapability` (`SwitchStateBase.cpp:4106-4151`, which advertises `FINE_GRAIN_ECMP`, `PROTECTION`, `CLASS_BASED`, `DYNAMIC_ORDERED_ECMP`, `P2P`/`P2MP`).
